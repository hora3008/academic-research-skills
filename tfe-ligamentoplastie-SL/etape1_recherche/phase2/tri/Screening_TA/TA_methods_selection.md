# Selection process - title/abstract screening

Records retrieved from Europe PMC (n = 466), PEDro (n = 4), PubMed/MEDLINE (n = 531) were combined and de-duplicated with the sr-screener skill (version 1.0.0) of the open-source Academic Research Skills suite (https://github.com/Imbad0202/academic-research-skills), running in Claude Code, which matches PMIDs, DOIs and normalised titles with publication year (plus or minus one year); 439 duplicates were removed, leaving 562 unique records. Titles and abstracts were screened against the pre-specified eligibility criteria of the review protocol. Each record was assessed independently by two AI reviewers (both Claude Sonnet (Claude Code alias 'sonnet'; exact model ID to be read from the run journal), prompted with different expert personas) that were given the same written protocol and decision rules and did not see each other's decisions. Disagreements between advancing (include or unclear) and excluding a record (5 records) were resolved by a third AI reviewer (Claude Sonnet (Claude Code alias 'sonnet'; exact model ID to be read from the run journal)) that re-read the record. The two reviewers agreed on advance-versus-exclude decisions for 99.1% of records (Cohen's kappa = 0.96; prevalence-adjusted bias-adjusted kappa = 0.982).
