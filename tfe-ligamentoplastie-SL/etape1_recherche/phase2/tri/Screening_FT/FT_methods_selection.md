# Selection process - full-text assessment

Of 75 reports sought for retrieval, 59 could not be retrieved. 16 full-text reports were assessed independently by two AI reviewers (both Claude Sonnet (Claude Code alias 'sonnet'; exact model ID to be read from the run journal), prompted with different expert personas) using the sr-screener skill (version 1.0.0) of the open-source Academic Research Skills suite (https://github.com/Imbad0202/academic-research-skills), running in Claude Code; each reviewer recorded one exclusion reason and the page supporting it. Disagreements were resolved by a third AI reviewer (Claude Sonnet (Claude Code alias 'sonnet'; exact model ID to be read from the run journal)).
